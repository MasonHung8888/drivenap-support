# DriveNap Website

DriveNap 的產品介紹、客服支援與隱私權網站。

## Pages

- `dist/index.html` — 產品介紹與安全省電流程
- `dist/support.html` — FAQ、問題排除與客服聯絡方式
- `dist/privacy.html` — 隱私權政策

## Privacy boundary

This repository contains only the public support website. It must never contain
the DriveNap application source code, signing identities, provisioning profiles,
user Volume UUIDs, device serial numbers, private support reports, or credentials.
