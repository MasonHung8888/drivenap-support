MACBOOK 外接儲存裝置適用

不用時安全休息，需要時快速回來。

DriveNap 為 macOS 外接 SSD 與 HDD 提供睡眠前安全卸載、喚醒後條件式掛載與 Battery Guardian，減少不必要的背景存取，同時把資料安全放在省電之前。

為外接磁碟設計的安全省電流程

不依賴特定橋接晶片。只要 macOS 能正常管理該外接卷宗，核心安全卸載功能就能運作。

Zz

Sleep Fast Path

Mac 進入睡眠前，以原生 Disk Arbitration 安全卸載指定磁碟，完成後才放行睡眠。

↻

條件式自動掛載

只有前一次確實由 Sleep 自動卸載成功，喚醒後才允許恢復掛載，避免誤操作。

BG

Battery Guardian

使用電池且磁碟長時間閒置時，先檢查 I/O，再倒數執行安全卸載。

I/O

忙碌保護

檔案仍被 App 使用時取消卸載並提示可能的占用程式，不強制中斷資料存取。

SSD

通用外接儲存

支援使用者指定的外接 SSD 或 HDD，並使用穩定卷宗身分保存個別設定。

LE

低耗電監測

優先採事件驅動；背景與未掛載狀態降低監測頻率，Mac 睡眠時停止一般輪詢。

先確認安全，再執行省電。

DriveNap 不會直接切斷 USB 供電，也不會發送 vendor-specific 或 NVMe 電源指令。它的工作是安全停止檔案系統 I/O，卸載指定卷宗，再交由 macOS、外接盒與磁碟執行原生電源管理。

1
偵測事件Sleep、鎖屏、電池與閒置狀態
2
確認 I/O 安全忙碌就取消，不使用 force unmount
3
安全卸載使用 macOS 原生 Disk Arbitration
4
需要時恢復依使用者設定與成功旗標重新掛載

第一次使用，只要四個步驟

DriveNap 只操作你明確選擇的外接卷宗。

選擇外接 SSD 或 HDD

從「設定」選擇要管理的外接磁碟根目錄並保存授權。

選擇省電模式

可使用智慧省電、最大省電，或自行調整 Guardian、鎖屏與 Sleep 選項。

確認手動掛載與卸載

先完成一次安全卸載與重新掛載，確認目前硬體組合能正常使用。

進行一次 Sleep／Wake 測試

從事件紀錄確認 Sleep 卸載成功，以及喚醒後是否依設定恢復掛載。

隱私優先

磁碟資料不會上傳

DriveNap 不需要帳號，不讀取或上傳檔案內容。設定、事件紀錄及睡眠統計保存在你的 Mac。

重要說明

省電幅度依硬體而異

安全卸載不等於 USB 斷電。實際效果會受到 Mac、外接盒、Bridge、SSD／HDD 與 macOS 電源管理影響。
